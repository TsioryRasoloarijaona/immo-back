# DossierModificationsController

Onglet « Modifications » de la fiche dossier (`ComModification`) : description, dates de demande, de validation technique et de validation client, coût, prix de vente HT et TTC, état, notes. Après chaque écriture, `ComFolder.ModificationsAmount` et `ModificationsAmountHT` = Σ des prix des demandes acceptées ou réalisées (`Sale.cs`) ; si « Intégrer le montant des modifications dans le calcul du prix de vente » est coché, le prix de vente = prix après remise + modifications ; puis le net à payer est recalculé et le dossier signé. Hors prix, `ecartSchema` donne ce qui manque au schéma de financement en lignes « Modifications » : le passage de statut le contrôle (`Sale.cs:VerifSchema`, « Votre schéma de financement pour les modifications ne correspond pas au montant contractuel »). La recopie dans l'écran Modification du module Projet, citée par l'aide, n'est pas reproduite (module hors périmètre).
