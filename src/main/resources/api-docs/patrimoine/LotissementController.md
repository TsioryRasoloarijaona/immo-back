# LotissementController

Écran OMRAN « LOTISSEMENTS » en lecture : lots de terrain, c'est-à-dire terrains rattachés à une tranche et de
vocation autre que PROJET. La fiche d'un lot est celle du terrain (`/api/terrains/{id}`).

## lister

Lots des tranches visibles (société du programme active). Mêmes filtres que `GET /api/terrains`.
