# RendezVousController

Écrans « Tâches » et « Calendrier » d'OMRAN : lignes `AdmTask` de l'entité `AdmAppointment`, sans statut. Une tâche répond 404 ici. Réservé à l'Administrateur. Voir `instructions/FEATURE-admin-rendez-vous.md`.

## modifier

Les dates comparées sont les valeurs fusionnées : un champ absent vaut la date déjà en base. La source (`sourceId`, `sourceLibelle`, `sourceEntite`) ne bouge jamais.
