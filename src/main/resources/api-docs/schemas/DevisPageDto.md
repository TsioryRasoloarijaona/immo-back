# DevisPageDto

Liste paginée des offres (devis), avec la somme des prix de vente TTC de la page courante uniquement
(voir la description du champ pour le détail).

## sommePrixVenteTTCPage

Somme des prixVenteTTC des offres de la page courante uniquement (pas un total plein-filtre sur
l'ensemble des résultats) — offres sans montant renseigné exclues de la somme.
