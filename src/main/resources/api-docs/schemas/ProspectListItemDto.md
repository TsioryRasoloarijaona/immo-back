# ProspectListItemDto

## ice

Identifiant Commun de l'Entreprise (`CfgTier.ICE`). Ne pas confondre avec `FiscalCode`, qui est une
autre colonne et n'est pas servie.

## profession

Profession, alimentée par `CfgTier.Quality` — **mesurée à 0 ligne sur 13 664**, donc toujours nulle.
Servie pour rester cohérente avec la fiche, à ne pas proposer comme critère.
