# SyntheseAnnuelleDto

Synthèse annuelle : l'échéancier mois par mois, les ventes concrétisées et les encaissements de
l'année. Reprend l'écran d'accueil du logiciel de bureau, y compris son assiette, pour que les
chiffres restent comparables pendant la transition.

## echeancier

**Toujours 12 points, de janvier à décembre.** Un mois sans échéance vaut zéro et n'est jamais omis
: une courbe doit pouvoir se tracer sans reboucher de trous côté client.
